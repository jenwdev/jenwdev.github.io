# Portfolio 2026 — development workspace

This directory is the **new portfolio redesign** and lives only on the `portfolio-2026` branch until launch.

## Safety rules
- Do not edit or merge into `main` without explicit approval.
- Keep the existing live portfolio at the repository root unchanged during development.
- Before launch, create an `archive/portfolio-original` branch from the original `main` commit.
- When approved, move the finished redesign to the repository root on `main` so GitHub Pages serves it.
- A branch in this public repository is publicly readable on GitHub, even though GitHub Pages does not publish it automatically.

## Files
- `index.html` — initial homepage prototype; content and copy are not final.
- `css/styles.css` — self-contained starter styles.
- Future additions: `case-studies/`, `assets/`, `js/` as needed.

## Local preview
Open `2026/index.html` in a local browser or use the VS Code Live Server extension. Relative asset paths are scoped to this directory.
